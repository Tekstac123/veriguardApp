# Regulatory Digest: Digital Personal Data Protection Act, 2023 (Training Summary)
*Deccan Commonwealth Bank - synthetic training data*

## 0. Disclaimer

This is a DCB-authored training summary, not legal text. Always verify against the official source before relying on it.

## 1. Lawful Processing

Personal data may be processed for a lawful purpose with the consent of the Data Principal or for certain legitimate uses specified in the Act, which include compliance with law.

## 2. Data Fiduciary Obligations

Data Fiduciaries must ensure accuracy, implement reasonable security safeguards, and erase personal data when the purpose is served, unless retention is required by law.

## 3. Breach Notification

Personal data breaches must be notified to the Data Protection Board and to each affected Data Principal.

## 4. Penalties

Failure to take reasonable security safeguards can attract penalties of up to Rs 250 crore.
